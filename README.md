# The Night Coder — Portfolio

A zero-dependency, single-page portfolio: animated starfield with shooting stars, interactive terminal,
⌘/Ctrl+K command palette, 3D-tilt project cards, orbiting skill graph, night/dawn theme and a few easter eggs.

## Run
Open `index.html`, or `python3 -m http.server` and visit http://localhost:8000.

## Customize
Edit the `projects`, `skills` and `typedWords` arrays at the top of `script.js`, and the copy in `index.html`.
